# 5. 시연 프롬프트 (복붙)

채팅 도구는 기관 정책을 따르세요.  
키트 폴더를 워크스페이스로 연 뒤, AGENTS.md / 이 문서를 읽게 합니다.

---

## 안전 선언 (말 10초)

> 가상 사례입니다. 실제 사람·환자·학생 식별정보는 쓰지 않습니다.  
> 시트 내용은 초안이며, 사람이 확인한 뒤 사용합니다.

---

## P0 — 역할 (선택 · 1회)

```text
당신은 교육·행정 준비를 돕는 스프레드시트 작성 보조입니다.
chat-to-sheets-kit 의 docs/04_domain_rules.md 규칙을 따르세요.
실명·학번·연락처·실기관 식별정보를 만들지 마세요.
불확실하면 "확인 필요"로 적으세요.
가능하면 .env 의 시트(DemoBoard)에 Google Sheets API로 직접 작성하세요.
결과는 초안이며 최종 확인은 사람입니다.
```

---

## P1 — 메인 (필수)

```text
빈 구글시트 DemoBoard 에 가상 시나리오로
「신규 프로그램 오리엔테이션 준비 체크표」를 작성해 줘.

규칙 (docs/04_domain_rules.md):
- A 그룹(필수/선택/참고)
- B 할 일
- C 참고·벤치마크(합산 제외)
- D 이번 잔여 건수(합산)
- E 담당 역할(직함만)
- F 상태
- G 사람이 확인할 것
- 필수 5~8행, 선택 1~2행, 참고 1행(C에 비교 숫자, D 비움, 합산 금지)
- D열 필수 SUMIF 요약 행
- A1 안전 안내 유지 또는 그 아래부터 표
- 실데이터·실명 금지
작성 후 채팅에 요약 표도 짧게 보여 줘.
```

또는 스크립트만:

```bash
python scripts/run_demo_s1.py
```

---

## P2 — 수정

```text
DemoBoard 표를 수정해 줘.
1) "안전 교육 자료 점검" 행 상태를 "확인 필요"로
2) 필수 SUMIF 가 맞는지 검증
3) 맨 아래 참고 행: "규정 문서와 안내문 문구 대조" (합산 제외)
API로 반영. 실명 금지.
```
