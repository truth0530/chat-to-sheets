# 이 키트가 하는 일 / 하지 않는 일

## 하는 일

| 목표 | 설명 |
|------|------|
| **연결** | 본인 Google 계정 · Cloud 프로젝트 · Sheets/Drive API |
| **권한** | 서비스 계정(JSON) + 스프레드시트 편집자 공유 |
| **규칙** | 표의 열·합산·금지를 MD로 고정 |
| **시연** | 채팅/스크립트가 빈 시트에 **가상** 표를 씀 |
| **습관** | 초안 → **사람 확인** |

## 하지 않는 일

| 비목표 | 이유 |
|--------|------|
| 특정 학교·병원·회사 업무 자동화 완제품 | 받는 사람 환경이 모두 다름 |
| 실제 명단·예산·환자 정보 예시 | 정보보호 · 패키지 배포 부적합 |
| “로그인 없이 완전 자동” | Google은 브라우저 동의가 필요 |
| 서비스 계정이 모든 파일을 대신 소유 | SA Drive 용량이 0인 경우가 많음 |

## 비유

```text
도메인 MD  = 레시피
API·SA     = 부엌 문 열쇠
빈 시트    = 도마
AI 채팅    = 보조 요리사
사람       = 시식·최종 책임
```

## 성공 기준 (받는 사람 기준)

1. 브라우저에서 본인 시트가 열린다.  
2. `smoke_test.py` 가 셀에 글을 쓴다.  
3. 채팅 또는 `run_demo_s1.py` 로 가상 표가 채워진다.  
4. 표에 **실존 개인·기관 식별정보가 없다.**
